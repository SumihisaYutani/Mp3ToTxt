# 機能仕様書

**システム名**: Mp3ToTxt 音声文字起こしアプリ
**バージョン**: 0.1
**作成日**: 2026-10-11

---

## 1. システム概要

音声ファイル（MP3・WAV 等）をローカル環境で AI 処理し、テキストに変換するデスクトップアプリケーション。インターネット接続は初回モデルダウンロード時のみ必要。APIキー不要。

---

## 2. 動作環境

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / 11 (64bit) |
| ランタイム | Qt 6.8 以上 |
| Python | 3.8 以上（自動検索） |
| Python ライブラリ | faster-whisper 1.2 以上、av 19 以上 |
| CPU | x86-64（GPU 不要） |
| ディスク | モデルファイル分（small: 約 244MB） |

---

## 3. 機能一覧

### 3.1 音声ファイル入力

| 項目 | 内容 |
|---|---|
| 対応フォーマット | MP3 / WAV / M4A / OGG / FLAC / WEBM / MP4 |
| 入力方法 | ① ドロップゾーンへのドラッグ＆ドロップ ② クリックによるファイル選択ダイアログ |
| 表示情報 | ファイル名・ファイルサイズ |

### 3.2 文字起こし設定

| 設定項目 | 選択肢 | デフォルト |
|---|---|---|
| 言語 | 自動検出 / 日本語 / 英語 / 中国語 / 韓国語 / フランス語 / ドイツ語 / スペイン語 | 日本語 |
| モデルサイズ | tiny / base / small / medium / large-v3 | small |

モデルサイズ設定はアプリ終了後も保持される（QSettings）。

### 3.3 文字起こし実行

- 「文字起こし開始」ボタンで処理を開始する。
- 処理中はステータスメッセージとインジケーターを表示する。
- セグメント単位でリアルタイムに結果を表示する（逐次表示）。
- モデルが未キャッシュの場合は初回ダウンロードを行い、進捗を 4 秒ごとに表示する。
- 処理中は「キャンセル」ボタンで中断できる。

### 3.4 ステータス表示

| 状態 | 表示内容 |
|---|---|
| 起動中 | 「起動中...」 |
| モデル初回ダウンロード | 「モデルをダウンロード中 (small) — 初回のみ数分かかります... (N秒経過)」 |
| モデルロード済み読み込み | 「モデルを読み込み中 (small)... (N秒)」 |
| 文字起こし中 | 「文字起こし中...」 |
| 完了 | 「完了！ N 文字」 |
| キャンセル | 「キャンセルしました」 |
| エラー | 「エラー: 内容」＋エラーダイアログ |

### 3.5 結果表示

- テキストエリアに文字起こし結果を表示する。
- 文字数を表示する。

### 3.6 改行ルール

| 条件 | 改行 |
|---|---|
| 「。」「！」「？」「…」「!」「?」で終わるセグメント | 空行（段落区切り） |
| 「、」「,」で終わるセグメント | 改行 |
| その他のセグメント | 改行 |

### 3.7 ファイル保存

| 形式 | 保存先 | ファイル名 |
|---|---|---|
| TXT（UTF-8） | 入力ファイルと同じフォルダ | 入力ファイルの拡張子を `.txt` に変換 |
| PDF（A4） | 入力ファイルと同じフォルダ | 入力ファイルの拡張子を `.pdf` に変換 |

例: `C:\音声\会議録音.mp3` → `C:\音声\会議録音.txt` / `C:\音声\会議録音.pdf`

### 3.8 クリップボードコピー

「コピー」ボタンで結果テキスト全体をクリップボードへコピーする。

### 3.9 エラー通知

エラー発生時はモーダルダイアログを表示し、Python の出力ログ（最大 800 文字）を含む詳細を提示する。

---

## 4. 制約事項

- 処理はすべて CPU で実行する（GPU 非対応）。
- Whisper API の制限（最大 25MB）は本アプリには適用されない（ローカル処理のため無制限）。
- Python が未インストールの場合は文字起こし機能を使用できない。

---

## 5. 処理フロー

```
ユーザー操作                アプリ (C++)               Python スクリプト
─────────────────────────────────────────────────────────────────
ファイル選択
    │
「文字起こし開始」 ──→ findPython() で Python 検索
                    ──→ ensureScript() でスクリプト書き出し
                    ──→ QProcess 起動（ノンブロッキング）
                                                ──→ av 互換パッチ適用
                                                ──→ モデルロード（ハートビート）
                    ←── STATUS: メッセージ受信 ←──
                    ←── SEGMENT: テキスト受信 ←── 音声解析・セグメント出力
                    ←── DONE 受信             ←── 処理完了
                    ──→ 結果表示・完了ステータス
    │
「TXT で保存」 ──→ 同フォルダに .txt 書き出し
「PDF で保存」 ──→ 同フォルダに .pdf 書き出し
```
