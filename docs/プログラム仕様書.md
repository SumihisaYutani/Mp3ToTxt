### 4.2 findPython() : QString

Python 実行ファイルのパスを以下の優先順で検索して返す。見つからなければ空文字列を返す。

```
① QStandardPaths::findExecutable("python")       PATH 上の python
② QStandardPaths::findExecutable("python3")      PATH 上の python3
③ %LOCALAPPDATA%\Programs\Python\*\python.exe    標準インストール先（降順・最新優先）
④ %LOCALAPPDATA%\Microsoft\WindowsApps\python.exe  Windows Store 版
```

---

### 4.3 ensureScript() : QString

`TRANSCRIBE_SCRIPT` 定数（埋め込み Python スクリプト）を `%TEMP%\mp3totxt_transcribe.py` に書き出し、そのパスを返す。毎回上書きするためコード変更が自動反映される。

---

### 4.4 transcribe(fileUrl, language)

**事前チェック**
1. `m_isProcessing == true` なら即時 return（多重起動防止）。
2. `toLocalPath()` で URL をローカルパスに変換し、ファイルの存在確認をする。

**起動処理**
1. `ensureScript()` でスクリプトを書き出す。
2. `m_sourceFilePath` に入力ファイルパスを保存する。
3. 各バッファ（`m_accumulatedText`, `m_lastError`, `m_rawOutput`）をクリアし、`isProcessing = true` にする。
4. `findPython()` で Python を検索する。見つからなければエラーシグナルを emit して return。
5. `QProcess` を生成し、以下を設定する。
   - プログラム: Python 実行ファイルパス
   - 引数: `スクリプトパス 音声ファイルパス 言語コード モデルサイズ`
   - チャンネルモード: `MergedChannels`
   - 環境変数: `PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8`
6. シグナルを接続する。
   - `readyReadStandardOutput` → `onProcessReadyRead`
   - `finished` → `onProcessFinished`
   - `errorOccurred` → `FailedToStart` 時のエラー処理ラムダ
7. `m_process->start()` でノンブロッキング起動する。

---

### 4.5 onProcessReadyRead()

`readyReadStandardOutput` シグナルで呼ばれる。

1. `m_process->readAll()` で全バッファを取得する（`\r` 対応のため `readLine()` は使わない）。
2. `[\r\n]+` で分割し、行ごとに処理する。
3. 各行を `m_rawOutput` に追記する（上限 3000 文字、超過分は先頭を切り捨て）。
4. プレフィックスに応じて処理を振り分ける。

| プレフィックス | 処理 |
|---|---|
| `STATUS:` | `setStatusMessage()` |
| `SEGMENT:` | セグメントを `m_accumulatedText` に追記 → 改行付与 → `setResult()` |
| `FATAL:` | `m_lastError` に保存 → ステータス更新 |
| その他 | 無視 |

**改行付与ロジック（SEGMENT 処理内）**

```
セグメント末尾文字
  ∈ {。！？…!?}  → "\n\n"（段落区切り）
  ∈ {、,}        → "\n"（改行）
  その他          → "\n"（改行）
```

---

### 4.6 onProcessFinished(exitCode, exitStatus)

1. `onProcessReadyRead()` を呼び出して残余出力を吸い上げる。
2. `m_process->deleteLater()` でプロセスを破棄し `nullptr` に戻す。
3. `setIsProcessing(false)` を呼ぶ。
4. `exitStatus == CrashExit` なら「キャンセルしました」を表示して終了（`cancelTranscription` による kill）。
5. `exitCode != 0` ならエラーメッセージを組み立てて `transcriptionError` を emit する。
   - `m_lastError` が空でない場合: `m_lastError` を使用
   - 空の場合: 「終了コード N + Python 生出力（末尾 800 文字）」を使用
6. `m_accumulatedText` が空なら「文字が検出されませんでした」を表示。
7. 正常完了なら `setResult()` → `setStatusMessage("完了！ N 文字")` → `transcriptionFinished` を emit する。

---

### 4.7 cancelTranscription()

`m_process->kill()` を呼ぶ。後処理は `onProcessFinished` の `CrashExit` 分岐が担う。

---

### 4.8 saveTxt()

1. `m_sourceFilePath` から出力パスを導出する（拡張子を `.txt` に変換）。
2. `QFile` を `WriteOnly | Text` で開く。
3. `QTextStream` で `m_result` を UTF-8 書き込みする。

---

### 4.9 savePdf()

1. `m_sourceFilePath` から出力パスを導出する（拡張子を `.pdf` に変換）。
2. `QPdfWriter` を A4・余白 20mm・解像度 96dpi で初期化する。
3. `QTextDocument` に `m_result` をセットし、`doc.print(&pdfWriter)` で出力する。

## 5. 埋め込み Python スクリプト（TRANSCRIBE_SCRIPT）

C++ の文字列定数として `TranscriptionManager.cpp` に埋め込まれ、実行前に一時ファイルに書き出される。

### 処理フロー

```
① 引数チェック（不足時は FATAL: 出力して終了コード 1）
② faster-whisper インポート確認（失敗時は FATAL: 出力して終了コード 2）
③ av.open() 互換パッチ適用（av 19+ の metadata_errors 引数削除への対応）
④ TQDM_DISABLE=1 設定（tqdm 出力抑制）
⑤ モデルキャッシュ確認 → STATUS: 出力（ダウンロード or 読み込み中）
⑥ ハートビートスレッド起動（4秒ごとに STATUS: 出力）
⑦ WhisperModel(model_size, device="cpu", compute_type="int8") でモデルロード
   失敗時: FATAL: 出力して終了コード 3
⑧ ハートビートスレッド停止
⑨ model.transcribe(audio_file, language=lang, beam_size=5) で文字起こし
   失敗時: FATAL: 出力して終了コード 4
⑩ セグメントを SEGMENT: プレフィックス付きで出力
⑪ DONE 出力
```

### 終了コード

| コード | 意味 |
|---|---|
| 0 | 正常終了 |
| 1 | 引数不足 |
| 2 | faster-whisper 未インストール |
| 3 | モデルロード失敗 |
| 4 | 文字起こし処理失敗 |
