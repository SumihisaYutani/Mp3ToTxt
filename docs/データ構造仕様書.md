## 2. TranscriptionManager クラス

### 2.1 概要

音声ファイルの文字起こし処理・結果管理・ファイル保存を担う C++ バックエンドクラス。
`QObject` を継承し、QML から `transcriptionManager` として参照される。

### 2.2 プロパティ

| プロパティ名 | 型 | READ | WRITE | NOTIFY | 説明 |
|---|---|---|---|---|---|
| `modelSize` | `QString` | ✓ | ✓ | `modelSizeChanged` | Whisper モデルサイズ。QSettings に永続化 |
| `isProcessing` | `bool` | ✓ | — | `isProcessingChanged` | 処理中フラグ |
| `result` | `QString` | ✓ | — | `resultChanged` | 文字起こし結果テキスト |
| `statusMessage` | `QString` | ✓ | — | `statusMessageChanged` | UI 向けステータス文字列 |

### 2.3 プライベートメンバ変数

| 変数名 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `m_modelSize` | `QString` | `"small"` | 選択中モデルサイズ |
| `m_isProcessing` | `bool` | `false` | 処理中フラグ |
| `m_result` | `QString` | `""` | 確定済みの文字起こし結果 |
| `m_statusMessage` | `QString` | `""` | 表示中ステータス文字列 |
| `m_process` | `QProcess*` | `nullptr` | 実行中の Python プロセス。未起動時は nullptr |
| `m_accumulatedText` | `QString` | `""` | セグメント逐次蓄積バッファ |
| `m_lastError` | `QString` | `""` | FATAL: で受信した最終エラーメッセージ |
| `m_rawOutput` | `QString` | `""` | Python 出力の生ログ（直近 3000 文字） |
| `m_sourceFilePath` | `QString` | `""` | 入力音声ファイルのローカルパス。保存先の導出に使用 |

### 2.4 公開メソッド（Q_INVOKABLE）

| メソッド | 引数 | 戻り値 | 説明 |
|---|---|---|---|
| `transcribe` | `fileUrl: QString, language: QString` | void | 文字起こし処理を開始する |
| `cancelTranscription` | なし | void | 処理中の Python プロセスを強制終了する |
| `saveTxt` | なし | bool | m_result を同フォルダに .txt で保存する |
| `savePdf` | なし | bool | m_result を同フォルダに .pdf で保存する |
| `getFileName` | `fileUrl: QString` | QString | URL からファイル名のみ取得する |
| `getFileSize` | `fileUrl: QString` | qint64 | ファイルサイズ（バイト）を返す |

### 2.5 シグナル

| シグナル | 引数 | 発火タイミング |
|---|---|---|
| `modelSizeChanged` | なし | m_modelSize 変更時 |
| `isProcessingChanged` | なし | m_isProcessing 変更時 |
| `resultChanged` | なし | m_result 変更時 |
| `statusMessageChanged` | なし | m_statusMessage 変更時 |
| `transcriptionError` | `message: QString` | エラー発生時 |
| `transcriptionFinished` | なし | 文字起こし正常完了時 |

## 3. Python プロセス間通信プロトコル

C++ と Python スクリプト間は標準出力（stdout）をテキストラインで通信する。
チャンネルは `QProcess::MergedChannels`（stderr を stdout にマージ）。

### 3.1 Python → C++ メッセージ形式

| プレフィックス | 内容 | C++ 側の処理 |
|---|---|---|
| `STATUS:` | ステータス文字列 | `setStatusMessage(メッセージ)` |
| `SEGMENT:` | 文字起こしセグメント 1 件 | `m_accumulatedText` に追記 → `setResult()` |
| `FATAL:` | 致命的エラーメッセージ | `m_lastError` に保存 → エラー表示 |
| `DONE` | 処理完了通知 | プロセス終了後に `onProcessFinished` で検知 |

### 3.2 Python プロセス起動引数

```
python.exe <スクリプトパス> <音声ファイルパス> <言語コード> <モデルサイズ>
```

| 引数 | 例 | 説明 |
|---|---|---|
| スクリプトパス | `%TEMP%\mp3totxt_transcribe.py` | 自動生成されるヘルパースクリプト |
| 音声ファイルパス | `C:\Users\...\audio.mp3` | 入力音声のローカルパス |
| 言語コード | `ja` / `en` / `auto` | `auto` の場合は自動検出 |
| モデルサイズ | `tiny` / `base` / `small` / `medium` / `large-v3` | Whisper モデル |

### 3.3 Python プロセス環境変数

| 変数名 | 値 | 目的 |
|---|---|---|
| `PYTHONUTF8` | `1` | Python の標準入出力を UTF-8 に固定 |
| `PYTHONIOENCODING` | `utf-8` | 同上（旧バージョン互換） |
| `TQDM_DISABLE` | `1` | tqdm プログレスバー出力を抑制 |

## 5. ファイル入出力

### 5.1 一時ファイル

| パス | 内容 | 生成タイミング |
|---|---|---|
| `%TEMP%\mp3totxt_transcribe.py` | 埋め込み Python スクリプト | `transcribe()` 呼び出し時（毎回上書き） |

### 5.2 Whisper モデルキャッシュ

| パス | 内容 |
|---|---|
| `~\.cache\huggingface\hub\models--Systran--faster-whisper-{size}\` | ダウンロード済みモデルファイル |

### 5.3 出力ファイル

| 形式 | パス | エンコーディング |
|---|---|---|
| TXT | `{入力ファイルと同ディレクトリ}\{ベース名}.txt` | UTF-8（BOM なし） |
| PDF | `{入力ファイルと同ディレクトリ}\{ベース名}.pdf` | — |

## 6. QML データバインディング

| QML プロパティ / 変数 | バインド先 | 説明 |
|---|---|---|
| `transcriptionManager.result` | `m_result` | 文字起こし結果。`resultChanged` で更新 |
| `transcriptionManager.isProcessing` | `m_isProcessing` | ボタン有効化・インジケーター制御 |
| `transcriptionManager.statusMessage` | `m_statusMessage` | ステータステキスト表示 |
| `transcriptionManager.modelSize` | `m_modelSize` | モデルサイズコンボボックス |
| `root.selectedFileUrl` | QML ローカル変数 | 選択中ファイルの URL（C++ に渡す前の保持） |
| `root.hasResult` | `transcriptionManager.result !== ""` | 保存ボタン表示制御 |
| `root.langCodes[]` | QML 配列 | 言語コンボ選択インデックス → 言語コード変換 |
